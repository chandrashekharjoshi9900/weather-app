# 🌦️ Weather App

A simple and responsive Weather App built using **HTML, CSS, and JavaScript**. The app fetches live weather data from the OpenWeatherMap API and displays the current weather of any city.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Current temperature in Celsius
- 💧 Humidity information
- 💨 Wind speed
- 🌤️ Dynamic weather icons
- 📱 Responsive user interface
- ⚡ Fast and lightweight

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API
